Скриншоты 11-13 Показать измененные данные через select, Скриншоты 14-15 объяснить модели, сериализаторы. - Диаграмма классов с детализацией бэкенда (домены методов по url с интерфейсами, перечислить все методы, модели, таблицы БД, 4 страницы фронтенда). Зависимость доменов от моделей сделать вашему коду, также указать зависимость страниц от доменов.

Пользователь/создатель пока зафиксирован (функция-singleton CurrentUserID(), id = 1).
Запросы с телом отправляются как multipart/form-data (поля формы). Файлы image и video передаются именно файлами.
Формат успешного ответа: {"status": "success", "data": ..., "message": "..."}.
Формат ошибки: {"status": "error", "description": "..."}.


## HTTP методы

### Услуги (признаки панкреатита по Рэнсону)

| Метод | Адрес | Описание | Параметры | Коды ответа |
|---|---|---|---|---|
| GET | `/api/pancreatitis-signs` | Список опубликованных признаков с фильтрацией на бэкенде. В каждой записи `is_mine` = 1, если создатель совпадает с текущим пользователем, иначе 0 | query: `filter` (часть названия), `max_value` (порог не больше) | 200, 400 |
| GET | `/api/pancreatitis-signs/feed` | Лента: опубликованные признаки | нет | 200 |
| GET | `/api/pancreatitis-signs/draft` | Черновик текущего пользователя (не более одного, id не указывается). Если черновика нет, `data` = `null` | нет | 200 |
| POST | `/api/pancreatitis-signs` | Создание черновика. Файлы сохраняются в MinIO под сгенерированными латинскими именами, имена записываются в БД | form-data: `title` (обязательно, до 100), `description` (до 500), `stage` (до 30), `threshold_value` (0..99999999), файлы `image` (jpg/png/gif/webp, до 5 МБ), `video` (mp4/webm, до 50 МБ) | 201, 400, 409 (черновик уже есть), 500 |
| PUT | `/api/pancreatitis-signs/{id}/publish` | Публикация: черновик -> опубликован, бэкенд ставит дату формирования. Недостающие поля можно передать в этом же запросе | form-data (необязательно): `title`, `description`, `stage`, `threshold_value` | 200, 400, 403 (чужой), 404, 409 (не черновик) |
| DELETE | `/api/pancreatitis-signs/{id}` | Логическое удаление (статус `удален`), только своих признаков | нет | 200, 400, 403, 404, 409 |
| POST | `/api/pancreatitis-signs/{id}/like` | Лайк от текущего пользователя. `like=1` ставит, `like=0` снимает (повтор безопасен). Лайкнуть можно только опубликованный признак | form-data: `like` (0 или 1) | 200, 400, 404 |

### Пользователи

| Метод | Адрес | Описание | Параметры | Коды ответа |
|---|---|---|---|---|
| POST | `/api/users` | Регистрация. Пароль хранится в виде bcrypt-хеша, `is_moderator` всегда false | form-data: `login` (до 25), `password` (6..72) | 201, 400, 409 (логин занят) |
| POST | `/api/auth/login` | Аутентификация (заглушка для лабораторной №4) | нет | 200 |
| POST | `/api/auth/logout` | Деавторизация (заглушка для лабораторной №4) | нет | 200 |

### Поля признака в ответах

| Поле | Тип | Описание |
|---|---|---|
| `id` | число | идентификатор |
| `title` | строка | название критерия |
| `description` | строка | описание |
| `status` | строка | `черновик` / `опубликован` |
| `stage` | строка | этап оценки («При поступлении», «Через 48 часов») |
| `threshold_value` | число | пороговое значение |
| `image_url`, `video_url` | строка | ссылки на файлы в MinIO (если файл не загружали, ссылка на файл по умолчанию) |
| `created_at`, `formed_at` | дата | создание и формирование (публикация) |
| `likes_count` | число | количество лайков |
| `is_liked` | 0/1 | текущий пользователь поставил лайк |
| `is_mine` | 0/1 | создатель признака совпадает с текущим пользователем |

## Таблицы БД

### `pancreatitis_users`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | bigserial | первичный ключ |
| `login` | varchar(25) | not null, unique |
| `password` | varchar(100) | not null (bcrypt-хеш) |
| `is_moderator` | boolean | not null, по умолчанию false |

### `pancreatitis_signs`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | bigserial | первичный ключ |
| `title` | varchar(100) | not null |
| `description` | varchar(500) | |
| `status` | varchar(15) | not null, по умолчанию `черновик`, check: `черновик` / `опубликован` / `удален` |
| `image_url` | varchar(255) | имя файла изображения в MinIO |
| `video_url` | varchar(255) | имя файла видео в MinIO |
| `stage` | varchar(30) | |
| `threshold_value` | numeric(10,2) | |
| `created_at` | timestamptz | not null |
| `formed_at` | timestamptz | дата публикации |
| `creator_id` | bigint | not null, внешний ключ на `pancreatitis_users.id` |

Уникальный частичный индекс: один черновик на пользователя (`creator_id` где `status = 'черновик'`).

### `pancreatitis_sign_likes`

| Поле | Тип | Ограничения |
|---|---|---|
| `id` | bigserial | первичный ключ |
| `user_id` | bigint | not null, внешний ключ на `pancreatitis_users.id` |
| `sign_id` | bigint | not null, внешний ключ на `pancreatitis_signs.id` |

Пара (`user_id`, `sign_id`) уникальна: один пользователь ставит один лайк на признак.

## Хранилище MinIO

Бакет задается в `.env` (`MINIO_BUCKET_NAME`). Файлы получают имена вида `image_<время>.jpg` и `video_<время>.mp4`, в БД хранится только имя, а ссылка собирается из `MINIO_PUBLIC_URL`, имени бакета и имени файла.
